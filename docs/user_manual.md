# 用户手册 (User Manual)

## 1. 快速开始
欢迎使用“未来图书馆”小说阅读系统。本系统提供简洁高效的纯净阅读体验。

## 2. 功能操作指南

### 2.1 发现小说
- **浏览**: 在首页你可以看到当前系统推荐的热门小说。
- **搜索**: 使用顶部的搜索框，输入小说名称或关键词即可快速定位书籍。

### 2.2 查看书籍详情
- 点击感兴趣的小说卡片，进入详情页面。
- 你可以查看书籍的完整简介及更新章节数。
- 点击“开始阅读”将跳转到第一章，或在目录中点击特定章节进入。

### 2.3 沉浸阅读
- 阅读页采用了护眼的暖色纸质风格。
- 点击下方的“返回目录”可以随时回到书籍列表。

### 2.4 作者后台（章节草稿管理）
- 点击页面顶部的「✍️ 作者后台」进入作者工作台。
- **新建小说**: 在作者后台首页点击「新建小说」，填写标题、简介和封面图（可选）。
- **新增章节**: 进入某本小说的「章节管理」，点击「新增章节」会自动创建一篇草稿并打开编辑器。
- **保存草稿**: 在编辑器中修改章节标题和正文，点击「保存草稿」。草稿仅作者后台可见，读者前台不会展示。
- **发布章节**: 在编辑器或章节管理列表点击「发布」，章节即刻对读者可见。

## 3. 常见问题 (FAQ)

**Q: 为什么系统是浅色的？**
A: 为了提供更好的可读性，系统近期升级到了全新的浅色主题。

**Q: 我可以在移动端使用吗？**
A: 是的，系统完全适配移动端浏览器，你可以通过手机进行阅读。

**Q: 数据会丢失吗？**
A: 当前版本为内存存储演示版，重启容器后台数据会重置回初始种子数据。
