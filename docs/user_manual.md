# 用户手册 (User Manual)

## 1. 快速开始
欢迎使用“未来图书馆”小说阅读系统。本系统提供简洁高效的纯净阅读体验。

## 2. 功能操作指南

### 2.1 发现小说
- **浏览**: 在首页你可以看到当前系统推荐的热门小说。
- **搜索**: 使用顶部的搜索框，输入小说名称或关键词即可快速定位书籍。

### 2.2 查看书籍详情
- 点击感兴趣的小说卡片，进入详情页面。
- 你可以查看书籍的完整简介及更新章节数。
- 点击“开始阅读”将跳转到第一章，或在目录中点击特定章节进入。

### 2.3 沉浸阅读
- 阅读页采用了护眼的暖色纸质风格。
- 点击下方的“返回目录”可以随时回到书籍列表。

### 2.4 作者后台（写稿与发布）
点击顶部导航的「作者后台」进入创作中心：
- **创建小说**: 点击「创建小说」，填写书名（必填）、简介与封面 URL（可选），提交后自动进入章节管理页。
- **新增章节**: 在章节管理页点击「新增章节」，系统会先生成一份草稿并打开编辑器。
- **保存草稿**: 在编辑器中修改章节标题和正文，点击「保存草稿」。草稿不会出现在公开书库与目录中，只有作者后台能看到。
- **发布章节**: 点击「保存并发布」（或在章节管理页点击「发布」），章节即对所有读者可见；之后仍可继续修改，改动会同步到公开侧。
- **状态区分**: 章节管理页中黄色「草稿」标签表示未发布，绿色「已发布」标签表示已上线。

## 3. 常见问题 (FAQ)

**Q: 为什么系统是浅色的？**
A: 为了提供更好的可读性，系统近期升级到了全新的浅色主题。

**Q: 我可以在移动端使用吗？**
A: 是的，系统完全适配移动端浏览器，你可以通过手机进行阅读。

**Q: 草稿会被读者看到吗？**
A: 不会。未发布（DRAFT）章节只在 `/author` 作者后台可见；公开接口不返回草稿，直接访问草稿链接会提示“章节不存在或尚未发布”。

**Q: 数据会丢失吗？**
A: 当前版本为内存存储演示版，重启容器后台数据会重置回初始种子数据。
